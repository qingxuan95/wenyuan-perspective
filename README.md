# 🎨 文渊视角 — 品牌视觉设计 Skill

> 将文渊（花西子原视觉合伙人）的品牌设计思维蒸馏为 AI 可执行的设计顾问能力。

## 这是什么？

这是一个 **WorkBuddy Skill**（AI 技能模块），通过深度调研文渊的公开访谈、方法论文章、品牌案例和行业评价，提炼其核心设计思维框架，让 AI 能够以文渊的视角辅助品牌视觉设计工作。

## 人物简介

**文渊（李渊）** — 花西子原视觉合伙人（2017-2025），淘宝大学前精英班讲师，中国电商协会讲师。

- 主导构建了花西子的"东方彩妆"视觉识别体系，站酷作品人气突破1000万
- 代表作：雕花口红、苗族印象（站酷31万浏览/842评论）、傣族印象、花神系列
- 水密码2017-2018年电商视觉体系操刀者
- 著有《电子商务网页设计与制作》

## 安装方法

### WorkBuddy 安装

将此 Skill 目录放置到 WorkBuddy 的 skills 目录下：

```bash
# 用户级安装（所有项目可用）
~/.workbuddy/skills/wenyuan-perspective/

# 或项目级安装
<project>/.workbuddy/skills/wenyuan-perspective/
```
